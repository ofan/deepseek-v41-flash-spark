`vendor/` and `patches/` are the source inputs used by the recipe. `sources.lock.json`
is the asset/source pin set. No external engine checkout is required.

The dated layer-audit, transfer, remediation and publication JSON/Markdown records
are **historical release evidence, not setup instructions**. Their earlier private/
held states describe those dates, not the current public artifact. Read current
`completion-report.md`, `public-release.json` and the anonymous readback receipt for
current access. The protected predecessor is not downloadable through this recipe.
Four-rank GPU qualification of the sanitized public image is still pending.
